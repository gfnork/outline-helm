This is a community-maintained chart using the experimental upstream Discourse image.

Create the referenced database and Redis Secrets before starting pods.
Create the PostgreSQL database and required extensions before running migrations.
Migrations never run automatically on web pod startup.

Read charts/discourse/README.md for the staged install/upgrade procedure.
Do not attach a Bitnami application PVC directly: its layout differs from /shared.
Back up the database AND uploads before migrating or upgrading.
